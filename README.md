# Hệ thống quản lý đồ án tốt nghiệp

## 1. Giới thiệu đề tài

Xây dựng hệ thống quản lý đồ án tốt nghiệp sử dụng kiến trúc SOA và REST API.

Hệ thống hỗ trợ quản lý:
- Sinh viên
- Đề tài tốt nghiệp
- Đăng ký đề tài

## 2. Công nghệ sử dụng

- Backend: Node.js + Express.js
- Database: MySQL
- Frontend: HTML, CSS, JavaScript
- API Testing: Postman
- Quản lý mã nguồn: GitHub

## 3. Chức năng chính

### Quản lý sinh viên
- Thêm sinh viên
- Xem danh sách sinh viên
- Xem thông tin sinh viên
- Cập nhật sinh viên
- Xóa sinh viên

### Quản lý đề tài
- Thêm đề tài
- Xem danh sách đề tài
- Cập nhật đề tài
- Xóa đề tài

### Quản lý đăng ký
- Đăng ký đề tài
- Xem danh sách đăng ký
- Cập nhật đăng ký
- Xóa đăng ký
